# 💗 Bachcha Birthday Website

A beautiful, interactive birthday celebration website for Bachcha's birthday on **13 September 2011**.

## ✨ Features

- **Elegant Landing Page**: Click to enter with animated starfield background
- **Personalized Message**: Heartfelt birthday greeting in Hindi & English
- **Photo Gallery**: Showcase beautiful moments together
- **Music Player**: "Be Intehaan" by Atif Aslam embedded via YouTube
- **Responsive Design**: Works perfectly on mobile, tablet, and desktop
- **Dark Theme**: Luxurious plum, gold, and cream color palette

## 🚀 Quick Start

1. Clone or download this repository
2. Add your photos to the `images/` folder (or update paths in `index.html`)
3. Open `index.html` in a web browser

## 📁 Project Structure

```
bachcha-birthday/
├── index.html          # Main website file
├── README.md          # This file
└── images/            # Folder for photos (create this and add your images)
    ├── photo1.jpg
    ├── photo2.jpg
    ├── photo3.jpg
    ├── photo5.jpg
    ├── photo6.jpg
    ├── photo7.jpg
```

## 🌐 Deploy to GitHub Pages

1. Go to your repository **Settings** → **Pages**
2. Select **Main** branch as the source
3. Your site will be live at: `https://golumonu.github.io/bachcha-birthday`

> Make sure to add the `images/` folder with your photos before deploying!

## 💝 Customization

Edit `index.html` to personalize:
- Change the greeting message in the first section
- Update photo paths in the gallery grid
- Modify the YouTube song or embed a different video
- Adjust colors in the `:root` CSS variables
